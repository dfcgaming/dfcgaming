## About me

I'm **Dylan**, the developer behind **dfcgaming**. I work across web development and Minecraft, with **Laravel, HTML, CSS, JavaScript, Node.js, and Java** as the technologies I know best.

On the web, my focus is full stack development: **Laravel and Livewire** for application features, and **HTML, CSS, SCSS, and JavaScript** for the interface. I like being able to work on both sides of an application, from the logic behind a feature to the way it looks and feels in the browser.

My Java work is mostly about **Minecraft plugins**. That side of development gives me a different way to build: writing features that become part of a server and change what players can do inside the game. My public repositories also include resource packs from my Minecraft projects.

I'm connected with **[SiteNomads](https://sitenomads.nl)**, and my GitHub brings together that web development work, personal tools, Minecraft projects, and the open-source software I explore along the way.

## Selected projects

### StructlyDiagrams

**A visual tool for documenting IT infrastructure.**

[View repository](https://github.com/dfcgaming/StructlyDiagrams) · [Open the application](https://dfcgaming.github.io/StructlyDiagrams/)

StructlyDiagrams is my browser-based infrastructure diagram builder. It lets you put servers, firewalls, switches, VLANs, Active Directory, Microsoft 365, VPNs, and other components onto a canvas and connect them into a diagram.

The goal is practical: make it easier to turn an infrastructure setup into something you can see, annotate, save, and share.

- Drag and drop components, then connect them with labeled relationships.
- Edit properties, services, labels, and notes in an inspector panel.
- Collapse branches, highlight labels, and arrange the diagram with automatic layout.
- Save and reload diagrams as **JSON**, or export them as **SVG and PNG**.

It uses **TypeScript, SCSS, and Webpack**, with vanilla DOM manipulation and no runtime dependencies. The application runs as a static page, without a backend or login. GitHub Actions builds and deploys it to GitHub Pages.
