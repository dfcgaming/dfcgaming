## About Me

Hi, I'm **Dylan**, also known as **dfcgaming**. I'm a full-stack developer with hands-on experience building web applications, Java-based systems, real-time services, infrastructure tools, and mobile applications.

I enjoy projects that connect multiple parts of a system: an intuitive frontend, reliable backend logic, databases, APIs, and the infrastructure needed to deploy and run everything. My work includes hosting-management software, infrastructure diagramming, collaborative applications, and complex Minecraft plugins.

I'm also interested in **ethical hacking and cybersecurity**, particularly understanding how systems work, identifying security boundaries, and building software with security in mind.
